# Student Assignment Tracker

## Project Overview
The Student Assignment Tracker is a simple web application that helps students organize assignments, keep track of due dates, and mark completed work.

## Project Files
- index.html: Contains the webpage structure and layout.
- style.css: Contains the design and styling of the application.
- script.js: Contains the JavaScript that makes the assignment tracker interactive.
- README.md: Explains the project structure and how to open it.

## How to Run the Application
1. Download and extract the StudentAssignmentTracker ZIP folder.
2. Open the folder.
3. Double-click index.html to open the tracker in a web browser.

## Planned Features
- Add new assignments.
- Set and view assignment due dates.
- Mark assignments as completed.

## Team Collaboration
Team members will use the shared project files to develop and combine their assigned features.

## Completion Tracking (Card #932)
- Select an assignment's checkbox to move that assignment into **Completed Assignments**.
- Uncheck a completed assignment to return it to **My Assignments**.
- Completed assignments are visually marked; checking one does not change another.
- Works for the two sample assignments and assignments added using the form.
- Limitation: Completion changes are shown while the page is open; refreshing the page resets the demo.
